# 🔷 2. `heap_max.py`

```python
def heapify(arr, n, i):
```

👉 função que garante a propriedade de heap máximo no índice `i`

```python
    maior = i
```

👉 assume que o maior valor é o próprio nó

```python
    esq = 2*i + 1
    dir = 2*i + 2
```

👉 calcula índices dos filhos esquerdo e direito

```python
    if esq < n and arr[esq] > arr[maior]:
        maior = esq
```

👉 verifica se o filho esquerdo é maior

```python
    if dir < n and arr[dir] > arr[maior]:
        maior = dir
```

👉 verifica o filho direito

```python
    if maior != i:
```

👉 se algum filho for maior que o pai

```python
        arr[i], arr[maior] = arr[maior], arr[i]
```

👉 troca os valores

```python
        heapify(arr, n, maior)
```

👉 chama recursivamente para corrigir o heap abaixo
